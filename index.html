Sub-Bab 1

Pengertian & 3 Pilar Utama Sistem Komputer

Sistem Komputer adalah kumpulan perangkat-perangkat komputer (fisik dan non-fisik) serta manusia yang saling terhubung dan berinteraksi satu sama lain untuk melakukan proses pengolahan data, hingga menghasilkan informasi yang berharga.

Konsep Kunci: Komputer tidak akan bisa berfungsi jika salah satu dari ketiga pilar ini hilang. Ketiganya merupakan satu kesatuan tak terpisahkan!
Pilar 1
Hardware (Perangkat Keras)

Benda Fisik yang Nyata

Komponen fisik komputer yang dapat dilihat langsung, disentuh, dan diraba. Bertindak sebagai "raga" komputer untuk menerima input dan mengeksekusi instruksi.

Contoh Nyata:

Processor (CPU), RAM, SSD, Motherboard, Keyboard, Mouse, Monitor, Printer.

Pilar 2
Software (Perangkat Lunak)

Instruksi & Program Logika

Kumpulan program dan kode instruksi elektronik yang tidak memiliki wujud fisik, namun bertugas memerintahkan hardware untuk memproses data.

Contoh Nyata:

Windows 11, Linux, macOS, Android, Microsoft Word, Google Chrome, Game.

Pilar 3
Brainware (Pengguna Manusia)

Manusia Pengendali Sistem

Manusia yang mengoperasikan, membuat program, memelihara perangkat keras, dan memanfaatkan komputer untuk menyelesaikan pekerjaan sehari-hari.

Contoh Tingkatan:

Programmer (pembuat software), Administrator (pengelola server), Operator/Siswa (pemakai).

Mengenal Lebih Dekat 3 Peran Brainware:

Profesi Komputer
Tingkat 1 Kreator
Programmer (Pengembang)

Orang yang memiliki keahlian menulis instruksi kode dalam bahasa pemrograman (seperti Python, Scratch, Java) untuk menciptakan aplikasi atau game.

Tingkat 2 Pengelola
Administrator Sistem

Orang yang bertugas merawat, mengelola keamanan, mengatur jaringan internet, dan memastikan server komputer tetap beroperasi stabil 24 jam.

Tingkat 3 Pengguna
Operator / End-User (Siswa)

Pengguna akhir yang memanfaatkan program aplikasi yang sudah jadi untuk mengetik tugas sekolah, browsing riset, atau membuat presentasi.

Analogi Mudah: "Sebuah Mobil Balap"

Bayangkan sistem komputer seperti mobil:
• Hardware: Rangka mobil, mesin, roda, setir, dan pedal rem (komponen berwujud fisik).
• Software: Aturan lalu lintas, sistem transmisi otomatis, dan peta petunjuk GPS.
• Brainware: Sopir yang mengemudikan mobil tersebut ke tempat tujuan. Tanpa sopir, mobil secanggih apapun tidak akan bergerak!

Sub-Bab 2

Galeri Foto & Klasifikasi Perangkat Keras (Hardware)

Pelajari 4 kelompok utama perangkat keras lengkap dengan foto produk asli dan fungsinya:

1. Perangkat Masukan (Input Devices)

Memasukkan data teks, audio, gambar, atau sinyal kendali ke komputer

Input
Keyboard

Mengetik karakter huruf, angka, dan tombol fungsi perintah.

Input
Mouse Optik

Mengarahkan kursor pointer, klik ganda, dan scroll layar.

Input
Mikrofon

Menangkap gelombang suara untuk diubah jadi sinyal digital.

Input
Webcam

Merekam visual video tatap muka saat Google Meet / Zoom.

Input
Scanner

Memindai lembar dokumen fisik menjadi berkas file digital.

2. Perangkat Pemroses (Processing Devices)

Otak sentral pengolah data, kalkulasi aritmetika, dan pengendali sistem

Processing
CPU (Processor)

Otak utama komputer berisi miliaran transistor mikro yang mengeksekusi instruksi (ALU + CU).

Memory
RAM (DDR4 / DDR5)

Menampung data aplikasi yang sedang aktif berjalan. Bersifat sementara (Volatile).

Graphics
GPU (VGA Card)

Memproses grafis visual resolusi tinggi, game 3D, animasi, dan render video.

Circuit Board
Motherboard

Papan sirkuit utama tempat menghubungkan CPU, RAM, GPU, dan jalur data bus.

3. Perangkat Keluaran (Output Devices)

Menyajikan hasil olahan komputer dalam format visual, cetak, atau audio

Softcopy
Monitor Layar

Menampilkan antarmuka grafis sistem dan video secara visual di layar kaca.

Hardcopy
Printer

Mencetak tulisan dan foto digital ke lembaran kertas fisik (Hardcopy).

Audio
Speaker / Headset

Mengubah sinyal listrik audio menjadi gelombang suara yang terdengar di telinga.

Projection
Proyektor LCD

Menyorotkan tampilan layar ke dinding/layar lebar untuk presentasi di kelas.

4. Perangkat Penyimpanan (Storage Devices)

Menyimpan file sistem, aplikasi, dan dokumen secara permanen (Non-Volatile)

Super Cepat
SSD (Solid State Drive)

Menggunakan chip flash silikon berkecepatan tinggi, hening, dan tahan guncangan.

Kapasitas Besar
Harddisk (HDD)

Penyimpanan mekanik berbasis piringan magnetik yang berputar dengan motor.

Portabel
Flashdisk USB

Penyimpanan saku portabel yang praktis untuk menyalin tugas antar komputer.

Online Drive
Cloud Storage

Menyimpan file di server internet (Google Drive, OneDrive) dapat diakses di mana saja.

Catatan Penting Guru: Perbedaan RAM vs ROM vs SSD!

RAM (Random Access Memory)
Sifat: Volatile (Hilang saat listrik mati). Menampung data aplikasi yang sedang aktif berjalan.
ROM (Read Only Memory)
Sifat: Non-Volatile (Tetap tersimpan). Hanya bisa dibaca, berisi instruksi booting awal (BIOS/UEFI).
SSD / Harddisk
Sifat: Penyimpanan Sekunder. Tempat menyimpan sistem operasi, tugas sekolah, game secara permanen.
Sub-Bab 3

Galeri Foto & Jenis-Jenis Perangkat Lunak (Software)

Software adalah nyawa yang mengendalikan hardware dan menjembatani pengguna dengan komputer:

Fondasi Sistem

Sistem Operasi (OS)

Software induk yang mengelola seluruh sumber daya perangkat keras dan menyediakan lingkungan tempat aplikasi berjalan.

Contoh: Windows 11, macOS, Linux (Ubuntu), Android, iOS.
Produktivitas

Perangkat Lunak Aplikasi

Program siap pakai yang dirancang untuk membantu pekerjaan spesifik manusia (mengetik dokumen, riset, dan presentasi).

Contoh: MS Word, Google Docs, Excel, Chrome, Photoshop.
Pemrograman

Bahasa Pemrograman

Bahasa instruksi terstruktur yang digunakan oleh programmer untuk menyusun logika dan membangun program baru.

Contoh: Python, Scratch, C++, Java, JavaScript.
Pemeliharaan

Program Utilitas

Software pendukung yang bertugas memelihara stabilitas, mengamankan dari virus/malware, dan membersihkan memori.

Contoh: Windows Defender, WinRAR, CCleaner.

Jenis Antarmuka Pengguna (User Interface):

GUI (Graphical User Interface)

Antarmuka visual modern berbasis jendela aplikasi, ikon tombol, menu warna, dan pointer mouse. Sangat ramah pengguna (user-friendly).

CLI (Command Line Interface)

Antarmuka berbasis teks perintah hitam putih (contoh: Terminal Linux atau Command Prompt / PowerShell Windows).

Sub-Bab 4

Mekanisme Kerja CPU: Siklus Mesin (Machine Cycle)

Melihat bagian dalam Central Processing Unit (CPU) dan cara kerjanya menjalankan instruksi.

ALU (Arithmetic Logic Unit)

Bertugas melakukan seluruh perhitungan matematika (penjumlahan, pengurangan) serta perbandingan logika (AND, OR, NOT, lebih besar, lebih kecil).

CU (Control Unit)

Sebagai "polisi lalu lintas" yang mengontrol dan mengatur arus instruksi antar komponen komputer, mengambil instruksi dari memori, dan mengarahkan ALU.

Register & Cache

Memori berkecepatan paling tinggi di dalam inti prosesor yang digunakan untuk menyimpan instruksi dan data kecil yang sedang dieksekusi secara instan.

4 Tahapan Siklus Eksekusi Mesin:

Langkah 1 1
FETCH (Mengambil)

Control Unit mengambil perintah/instruksi berikutnya dari RAM/memori utama ke dalam register CPU.

Langkah 2 2
DECODE (Menerjemahkan)

CPU menerjemahkan perintah biner tersebut menjadi sinyal kendali yang dipahami oleh komponen chip.

Langkah 3 3
EXECUTE (Menjalankan)

ALU atau unit terkait menjalankan instruksi tersebut (misal menjumlahkan 2 angka atau membandingkan).

Langkah 4 4
STORE (Menyimpan)

Hasil dari eksekusi ditulis kembali ke register atau disimpan ke RAM untuk ditampilkan.

Sub-Bab 5

Representasi Data: Bahasa Biner & Pengalamatan Memori

Mengapa komputer hanya mengenal angka 0 dan 1?

Di dalam sirkuit mikroskopis prosesor, miliaran transistor elektronik hanya mengenal dua keadaan fisik: Ada Tegangan Listrik (Nyala / ON) yang dilambangkan dengan angka 1, dan Tidak Ada Listrik (Mati / OFF) yang dilambangkan dengan angka 0.

Oleh karena itu, seluruh tulisan teks, foto selfie, video YouTube, hingga lagu MP3 pada akhirnya diubah menjadi jutaan deretan angka biner 0 dan 1!

1 Bit (Binary Digit)
0 atau 1

Unit terkecil data digital (ibarat satu saklar lampu)

1 Byte (Bita)
8 Bit

Cukup untuk menyimpan 1 karakter huruf (contoh: huruf 'A')

1 Kilobyte (KB)
1.024 Byte

Sekitar satu halaman paragraf teks dokumen

1 Megabyte (MB)
1.024 KB

1 Gigabyte (GB) = 1.024 MB
1 Terabyte (TB) = 1.024 GB

Rumus Rahasia: Nilai Bobot 8-Bit (Pangkat 2)

Setiap posisi bit dari kanan ke kiri memiliki bobot nilai kelipatan pangkat 2:

Bit 7 (2⁷) Bit 6 (2⁶) Bit 5 (2⁵) Bit 4 (2⁴) Bit 3 (2³) Bit 2 (2²) Bit 1 (2¹) Bit 0 (2⁰)
128 64 32 16 8 4 2 1
Contoh Kasus: Berapakah nilai biner 00001011 dalam desimal?
Jumlahkan kolom yang berangka 1:
➔ (0×128) + (0×64) + (0×32) + (0×16) + (1×8) + (0×4) + (1×2) + (1×1)
➔ 8 + 2 + 1 = 11! Sangat mudah bukan?

Mata Pelajaran Informatika • Kurikulum Merdeka SMP Fase D

1. Tiga Pilar Sistem Komputer

• Hardware: Bagian fisik yang dapat dilihat dan diraba (CPU, Monitor, Mouse, RAM).

• Software: Program elektronik yang menjalankan instruksi (Sistem Operasi Windows/Linux, Browser, Office).

• Brainware: Manusia yang mengoperasikan komputer (Programmer, Administrator, Operator/Siswa).

2. Klasifikasi Perangkat Keras (Hardware)

• Input Device: Keyboard, Mouse, Scanner, Mikrofon, Kamera Webcam.

• Processing Device: CPU (ALU + CU + Register), GPU (Kartu Grafis), RAM, Motherboard.

• Output Device: Monitor, Printer, Speaker, Proyektor LCD.

• Storage Device: SSD (Solid State Drive), Harddisk (HDD), Flashdisk USB, Cloud Storage.

3. Siklus Mesin CPU (Fetch - Decode - Execute - Store)

1. Fetch: Control Unit mengambil instruksi dari RAM.

2. Decode: Menerjemahkan instruksi menjadi sinyal elektronik.

3. Execute: ALU mengeksekusi operasi logika/matematika.

4. Store: Menyimpan hasil kembali ke memori atau register.

4. Bilangan Biner (0 dan 1) & Konversi 8-Bit

Komputer hanya mengenal sinyal 0 (Off) dan 1 (On). 1 Byte = 8 Bit.

Bobot posisi 8-bit dari kiri ke kanan: 128, 64, 32, 16, 8, 4, 2, 1.
