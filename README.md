# Media Pembelajaran Interaktif: Sistem Komputer (Informatika SMP Kelas 8 Bab 4)

Media Pembelajaran Interaktif berbasis web untuk Mata Pelajaran **Informatika SMP Kelas 8 Bab 4: Sistem Komputer** sesuai dengan **Kurikulum Merdeka (Kemendikbudristek RI)**.

---

## 🌟 Fitur Utama

1. **Beranda & Tujuan Pembelajaran**: Menampilkan Capaian Pembelajaran (CP) Elemen Sistem Komputer Fase D, Tujuan Pembelajaran, serta peta jelajah konsep.
2. **Modul Materi Lengkap**:
   - **Sub-Bab 1**: Tiga Pilar Sistem Komputer (*Hardware, Software, Brainware*) & 3 Peran Brainware (*Programmer, Administrator, Operator*).
   - **Sub-Bab 2**: Galeri Perangkat Keras (*Input, Processing, Output, Storage*) lengkap dengan 20+ foto produk nyata.
   - **Sub-Bab 3**: Galeri Perangkat Lunak (*Sistem Operasi, Aplikasi, Bahasa Pemrograman, Utilitas*) & perbedaan GUI vs CLI.
   - **Sub-Bab 4**: Mekanisme Kerja CPU (*ALU, CU, Register*) & Siklus Mesin (*Fetch - Decode - Execute - Store*).
   - **Sub-Bab 5**: Bahasa Biner (*0 & 1*), Bit & Byte, serta Tabel Bobot Nilai 8-Bit.
3. **Laboratorium Interaktif (Hands-On Simulator)**:
   - 🎮 **Game Klasifikasi Hardware**: Tantangan menyortir 12 komponen hardware ke 4 kategori dengan indikator visual dan skor langsung.
   - ⚡ **Simulator Saklar Biner 8-Bit**: Saklar interaktif ON/OFF untuk mengubah bit biner menjadi angka desimal, karakter ASCII, dan mini quest tantangan.
   - 🔄 **Simulator Siklus IPOS**: Visualisasi alur instruksi (*Input ➔ Process ➔ Output ➔ Storage*).
4. **Kuis & Uji Kompetensi**:
   - 15 butir soal pilihan ganda standar Asesmen Nasional.
   - Pembahasan instan dan lembar evaluasi lengkap.
   - Nilai KKM 75, animasi perayaan kelulusan (Canvas Confetti & SFX Audio).
   - **Sertifikat Digital** berprestasi yang dapat langsung dicetak dengan nama siswa!
5. **Glosarium Istilah**: Kamus pintar 18 istilah teknologi komputer dengan pencarian *real-time*.
6. **Aksesibilitas**: Mode Gelap/Terang (*Dark/Light Mode*), efek suara (*Web Audio API*), dan fitur Cetak Rangkuman (*Print-friendly*).

## 🚀 Teknologi yang Digunakan

Cukup buka berkas `index.html` dengan browser peramban apa saja (Chrome, Edge, Firefox, Safari). Tidak memerlukan server backend khusus.
